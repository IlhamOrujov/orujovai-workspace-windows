# OrujovAI Workspace for Windows

The installer for OrujovAI Workspace on Windows 10 and 11 (64-bit).

**Download:** [work.orujovai.com/download?os=windows](https://work.orujovai.com/download?os=windows), or the latest file under [Releases](https://github.com/IlhamOrujov/orujovai-workspace-windows/releases/latest).

Workspace is an AI agent that does real work for your company: reports, research, documents, decks, data. The app gives it what a desktop app has: a window of its own, Quick Entry from anywhere (Alt+Space), screenshots and window captures, the tray next to the clock, files from Explorer, and notifications when a task finishes or needs your OK.

**Installing:** the installer isn't code-signed yet, so Windows asks once. Keep the download in your browser, then in "Windows protected your PC" choose **More info → Run anyway**. The app opens by itself.
